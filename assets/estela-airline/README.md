# ESTELA · concepto de aerolínea

**Estado: propuesta para revisión.** Esta carpeta no sustituye los logos actuales del sitio.

Nuevo concepto creado en Affinity mediante el plugin affinity-codex: wordmark **ESTELA** en mayúsculas, con tipografía sans serif firme y espaciado controlado; símbolo independiente que combina una E inclinada con un ala en ascenso. La dirección busca transmitir precisión, movimiento y calidad premium, manteniendo la paleta de Estela.

## Tres usos

| Familia | Uso |
| --- | --- |
| `estela-logotipo-*.svg` | Símbolo + nombre, composición horizontal principal |
| `estela-wordmark-*.svg` | Nombre ESTELA sin símbolo |
| `estela-isotipo-*.svg` | Emblema E/ala independiente |

`oscuro` corresponde a la variante para fondos claros; `claro`, a la variante para fondos oscuros. El logotipo incluye además versiones SVG monocromas negra y blanca para reproducción a una tinta.

Las tres familias se incluyen como **SVG editable**, **PNG transparente** y **WebP lossless transparente**. Los SVG de los logos contienen trazados vectoriales, sin texto dependiente de fuentes ni imágenes raster. Se pueden abrir y editar en Affinity.

## Paleta y tamaños

- Negro: `#06080a`; marfil: `#faf9f6`.
- Dorado para fondo claro: `#775a19`; dorado para fondo oscuro: `#e9c176`.
- Logotipo raster: 1710 × 320 px.
- Wordmark raster: 1300 × 320 px.
- Isotipo raster: 560 × 520 px.
